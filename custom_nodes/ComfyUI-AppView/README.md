# Comfy_Node_UI extension files

Copy this `ComfyUI-AppView` folder into your active ComfyUI installation's
`custom_nodes` directory and restart ComfyUI. This is an interface extension;
it does not add a computational node to the node menu.

This folder contains the extension and its UI code. The workflow JSON is opened
separately in ComfyUI. Dragging a JSON file does not install additional UI files.

See the [installation, usage and sharing guide](https://github.com/A-Laurent-Lab/Comfy_Node_UI#readme)
for the full steps, the optional example, and creating your own UI with an agent.
