# ComfyUI-App-View

This is the generic App View extension. It contains no workflow-specific UI.

Copy the `ComfyUI-App-View` folder into ComfyUI's `custom_nodes` folder and
restart ComfyUI. Separately supplied UI folders go in `web/renderers`.

See the [project README](https://github.com/A-Laurent-Lab/ComfyUI-App-View#readme).
