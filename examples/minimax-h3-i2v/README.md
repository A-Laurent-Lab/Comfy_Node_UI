# MiniMax H3 image-to-video example

This example is separate from the generic extension. Install it only when you
want to open `minimax-h3-i2v-app-view.json` with its custom interface.

1. Copy `ui/comfynodeui-minimax-h3-i2v` into
   `ComfyUI/custom_nodes/ComfyUI-App-View/web/renderers/`.
2. Restart ComfyUI and open `minimax-h3-i2v-app-view.json`.

The workflow contains its model links and normal ComfyUI node requirements.
